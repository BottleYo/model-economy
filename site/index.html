Free, open-source Codex plugin

Model Economy

A tiny edit should not need a committee.

Give Codex a division-of-labor guide: handle small jobs in the current task, request lighter models for suitable work, and keep design and review for risky changes. Model and reasoning settings are separate. Visible tasks need your authorization and host-tool support; this plugin does not switch your current chat's model or promise a cheaper bill.

What changed in v0.7.0?

Pick models and reasoning levels per role, reuse a visible task for its follow-up fix, and back up old settings before migration. No surprise amnesia after an update. Live desktop creation, continuation, and complex parallel trials were waived for this stable release and remain unverified. Bilingual release notes.

Already installed? Copy the reusable update prompt.

How it works

Simple

Main agent, no subagent, no strong request.

Mechanical

Fixed rules only, with a check for every result.

Standard

Main-agent or authorized visible-task execution with conditional evidence gates.

Large / high-risk

Architecture and final-review gates when enhanced roles are available.

Core first, enhancement optional

Core mode

All skills work after directory installation without local six-role files. High-risk work fails closed when isolated roles are unavailable.

Enhanced mode

The local CLI optionally installs six managed role definitions. Identity remains unverified.

Install

git clone https://github.com/BottleYo/model-economy.git
cd model-economy
codex plugin marketplace add .
codex plugin add model-economy@model-economy-public

That is the complete core-mode path. The optional enhanced-mode command and removal instructions are in the repository installation guide.
