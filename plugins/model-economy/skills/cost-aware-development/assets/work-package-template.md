# 工作包记录模板（v1）

仅在实际委派或跨会话持续工作时使用。由唯一协调者维护；字段和上限以 `cost-aware-development/references/routing-policy.json` 为准。填写后的实际记录不写入安装 state，也不得进入可移植档案或公开发布包；此空白模板可以随 Skill 发布。

```text
root_work_package_id:
work_package_id:
验收目标:
规则版本: 7
当前协调任务:
授权依据:
新建/继续及原因:

项目和真实工程:
Git 起点与基线:
文件主责:
依赖与集成顺序:

任务 ID / 宿主 ID:
创建中 ID:
请求标识:
动作: 创建 | 继续 | 重试 | 升级
执行状态: 已启动 | 未启动 | 未知
预算占位: 是 | 否
请求模型 / reasoning:
实际返回/未知:

预算：新上下文 / 执行请求 / strong 席位 / strong 请求 / 每 strong 角色请求:
计数完整性: 完整 | 待对账
状态: pending | running | awaiting_integration | completed | blocked
证据:
剩余问题:
```

不要复制凭据、个人数据、完整聊天或完整日志。模型未被工具回显时写“请求已提交，运行配置未确认”，不要由任务名称、角色名或回复文风推断实际模型。
